# Learning

Личный учебный репозиторий с конспектами, примерами кода и практическими заданиями по программированию, математике и формальным доказательствам.

## Содержание

### C++

Материалы по языку C++:

- основы программирования;
- объектно-ориентированное программирование;
- работа с памятью;
- шаблоны и стандартная библиотека;
- многопоточное программирование;
- практические задания и примеры кода.

### Go

Конспекты и примеры по языку Go:

- основы языка;
- функции, структуры и интерфейсы;
- коллекции и обработка ошибок;
- управление памятью;
- конкурентное и многопоточное программирование.

### Numerical Analysis

Материалы по численным методам:

- решение систем линейных уравнений;
- прямые и итерационные методы;
- оценка погрешностей;
- обусловленность и устойчивость вычислений.

### Rocq

Введение в язык формальных доказательств Rocq:

- базовые конструкции языка;
- логические выражения;
- функции и типы;
- основные тактики;
- построение и проверка доказательств.

## О репозитории

Репозиторий используется для хранения и систематизации учебных материалов. Содержание постепенно обновляется и дополняется по мере изучения новых тем.
