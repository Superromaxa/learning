# Learning

Личный учебный репозиторий: здесь я собираю конспекты, примеры кода, решения задач и небольшие эксперименты по мере обучения.

Цель репозитория — хранить материал в одном месте, чтобы можно было легко найти нужные конспекты.

Структура будет постепенно дополняться вместе с новыми темами. Для каждой темы можно держать рядом краткие заметки, ссылки на полезные материалы, код и собственные выводы.

Подробное оглавление появится позже, когда в репозитории накопится материал.
