# Rocq Tutorial 3: типы данных, вычисления и индукция

Этот туториал вводит конкретные данные в Rocq: конечные перечисления, сопоставление с образцом, натуральные числа, рекурсивные функции, доказательства по случаям и индукции.

## 1. Индуктивные типы

Простейший тип задаётся перечислением всех возможных значений:

```coq
Inductive color : Type :=
| red
| blue.
```

После этого:

```coq
color : Type
red   : color
blue  : color
```

`red` и `blue` называются **конструкторами**. У типа `color` нет других значений.

В туториале аналогично определены карты:

```coq
Inductive card := A | K | Q | J | F10 | F9 | F8 | F7.
```

## 2. Функции и `match`

Чтобы вычислять результат в зависимости от конструктора, используется `match`:

```coq
Definition inv (c : color) :=
  match c with
  | red  => blue
  | blue => red
  end.
```

Общий шаблон:

```coq
Definition f (x : T) :=
  match x with
  | constructor1 => result1
  | constructor2 => result2
  end.
```

Символ `_` означает «любое значение, которое здесь не нужно называть»:

```coq
match c, trump with
| A, _    => 11
| J, true => 20
| J, false => 2
end
```

## 3. Вычисление и равенство

Закрытые выражения Rocq может вычислять:

```coq
Eval compute in 2 + 2.
```

Команда:

```coq
simpl.
```

выполняет доступные вычисления в цели и гипотезах.

Если обе стороны равенства после вычисления совпадают, достаточно:

```coq
reflexivity.
```

Например:

```coq
Lemma calc : 200 + 200 = 400.
Proof.
  reflexivity.
Qed.
```

## 4. Доказательство по случаям

Если значение имеет конечное число конструкторов, его можно разобрать:

```coq
case: c.
```

Для `color` появятся две цели: случай `red` и случай `blue`. Для `card` появятся восемь случаев.

Имена внутренних данных можно получить с помощью шаблона:

```coq
case: value => [|x].
```

Например, у типа:

```coq
Inductive option_nat :=
| None
| Some : nat -> option_nat.
```

шаблон `[|x]` означает:

- первая ветка: `None`;
- вторая ветка: `Some x`.

Полезные команды для невозможных случаев:

```coq
discriminate.
contradiction.
```

`discriminate` закрывает противоречивые равенства разных конструкторов или разных вычисленных чисел. `contradiction` использует уже находящиеся в контексте несовместимые гипотезы.

## 5. Натуральные числа

Концептуально `nat` устроен так:

```coq
Inductive nat : Type :=
| O : nat
| S : nat -> nat.
```

Поэтому:

```text
0 = O
1 = S O
2 = S (S O)
3 = S (S (S O))
```

Любое натуральное число является либо `0`, либо `S n` для некоторого меньшего `n`.

## 6. Рекурсивные функции и `Fixpoint`

Рекурсивная функция определяется через `Fixpoint`:

```coq
Fixpoint double (n : nat) : nat :=
  match n with
  | O   => O
  | S m => S (S (double m))
  end.
```

Rocq разрешает рекурсивный вызов только на структурно меньшем аргументе. Поэтому `double m` допустим в ветке `S m`, а бесконечный вызов `foo n := foo n` запрещён.

## 7. Почему `0 + n` и `n + 0` различаются

Сложение рекурсивно по первому аргументу:

```coq
Fixpoint add n m :=
  match n with
  | O   => m
  | S p => S (add p m)
  end.
```

Поэтому:

```coq
0 + n
```

вычисляется сразу в `n`, а:

```coq
n + 0
```

не вычисляется, пока `n` остаётся переменной. Для доказательства `n + 0 = n` нужна индукция по `n`.

## 8. Индукция

Основной шаблон ssreflect:

```coq
elim: n => [|p IH].
- (* случай n = 0 *)
- (* случай n = S p, доступно IH *)
```

После `elim`:

- первая цель соответствует `0`;
- вторая — `S p`;
- `IH` является индукционной гипотезой для `p`.

Пример:

```coq
Lemma addn0 : forall n, n + 0 = n.
Proof.
  elim=> [|n IH].
  - reflexivity.
  - simpl.
    rw IH.
    reflexivity.
Qed.
```

### Когда использовать `case`, а когда `elim`

```text
case: n   разбирает 0 и S n, но не даёт индукционную гипотезу;
elim: n   разбирает 0 и S n и даёт гипотезу для меньшего n.
```

Если нужно только посмотреть на форму значения — `case`. Если доказательство для `S n` использует результат для `n` — `elim`.

## 9. Переписывание равенств

Если имеется:

```coq
IH : expression1 = expression2
```

то:

```coq
rw IH.
```

заменяет `expression1` на `expression2` в цели. В старых версиях и материалах курса может встречаться эквивалентная команда `rewrite IH`.

## 10. Boolean как proposition

После импорта:

```coq
Require Import ssrbool.
```

булево выражение может использоваться как утверждение:

```coq
le n m
```

в позиции proposition означает, что вычисление `le n m` должно дать `true`.

Поэтому:

```coq
Lemma b1 : true.
Proof. reflexivity. Qed.
```

а гипотеза `false` является невозможной:

```coq
Lemma b2 : false -> False.
Proof.
  move=> h.
  discriminate.
Qed.
```

## 11. Пользовательский порядок `le`

В туториале порядок задаётся вычислением:

```coq
Fixpoint le (x y : nat) :=
  match x, y with
  | 0, _       => true
  | S _, 0     => false
  | S x, S y   => le x y
  end.
```

Основные приёмы доказательств:

- `le_refl`: индукция по числу;
- `le_trans`: индукция по первому числу и случаи по остальным;
- `le_antisym`: одновременное снятие `S` с обеих сторон;
- `le0n`: непосредственное вычисление;
- `leP`: индукция и построение свидетеля через `exists`.

## 12. Рекурсивные списки

Необязательная часть вводит список натуральных чисел:

```coq
Inductive list : Type :=
| nil  : list
| cons : nat -> list -> list.
```

`nil` — пустой список, а `cons x tl` — список с головой `x` и хвостом `tl`.

Конкатенация рекурсивна по первому списку:

```coq
Fixpoint cat (l1 l2 : list) : list :=
  match l1 with
  | nil       => l2
  | cons x tl => cons x (cat tl l2)
  end.
```

Длина определяется аналогично:

```coq
Fixpoint size (s : list) : nat :=
  match s with
  | nil       => 0
  | cons _ tl => S (size tl)
  end.
```

Свойства `cat l nil = l` и `size (cat l1 l2) = size l1 + size l2` доказываются индукцией по `l` или `l1`, потому что именно по этому аргументу рекурсивны определения.

## 13. Быстрый алгоритм выбора тактики

```text
Выражение полностью вычисляется?              reflexivity / simpl
Переменная конечного индуктивного типа?        case:
Нужен результат для меньшего значения?         elim:
В контексте невозможное равенство/false?       discriminate
Есть подходящее равенство?                     rw
Цель существует?                               exists
Цель является стрелкой или forall?             move=>
```

Главный принцип туториала: сначала разбить значение на конструкторы, после чего вычисление часто делает оставшуюся цель простой или полностью решает её.
