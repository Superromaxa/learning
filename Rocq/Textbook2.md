# Функции в Rocq: подготовка ко второму файлу

## 1. У каждого выражения есть тип

Запись:

```coq
x : T
```

означает: выражение `x` имеет тип `T`.

Примеры:

```coq
3   : nat
A   : Prop
hA  : A
P   : nat -> Prop
P 3 : Prop
```

Важно различать:

```coq
P     : nat -> Prop  (* P — функция-предикат *)
P 3   : Prop         (* proposition о числе 3 *)
hP3   : P 3          (* доказательство этого proposition *)
```

## 2. Тип функции: `A -> B`

```coq
A -> B
```

— тип функции, которая принимает значение типа `A` и возвращает значение типа `B`.

Это одинаково работает для данных и доказательств:

```coq
nat -> nat   (* принимает число, возвращает число *)
A -> B       (* принимает доказательство A, возвращает доказательство B *)
```

Поэтому доказательство импликации является функцией.

## 3. Применение функции записывается пробелом

Если:

```coq
f : A -> B
x : A
```

то:

```coq
f x : B
```

Например:

```coq
PQ   : forall n, P n -> Q n
PQ 3 : P 3 -> Q 3
p3   : P 3

PQ 3 p3 : Q 3
```

Здесь нет скрытых логических связок:

1. `PQ` применяется к числу `3`;
2. полученная функция применяется к доказательству `p3`.

Применение ассоциируется влево:

```coq
f x y = (f x) y
```

## 4. Стрелка ассоциируется вправо

```coq
A -> B -> C
```

означает:

```coq
A -> (B -> C)
```

Такая функция последовательно принимает два аргумента:

```coq
f   : A -> B -> C
f a : B -> C
f a b : C
```

Но тип:

```coq
(A -> B) -> C
```

другой: функция принимает один аргумент, который сам является функцией `A -> B`.

## 5. Что означают скобки и двоеточия в `Lemma`

```coq
Lemma p1 (P : nat -> Prop) (n : nat) : P n -> P n.
```

Читается так:

- `p1` — имя леммы;
- `(P : nat -> Prop)` — параметр `P` указанного типа;
- `(n : nat)` — параметр `n` указанного типа;
- последнее `:` отделяет параметры от типа всей леммы;
- `P n -> P n` — утверждение, которое нужно доказать.

Эта запись эквивалентна:

```coq
Lemma p1 : forall (P : nat -> Prop) (n : nat), P n -> P n.
```

Скобки в `(P : nat -> Prop)` объединяют имя параметра с его типом. Они не означают вызов функции.

Скобки в `(P 3)` — просто группировка; здесь они необязательны:

```coq
(P 3) = P 3
```

## 6. Предикат — функция, возвращающая `Prop`

```coq
P : nat -> Prop
```

можно читать как семейство propositions, по одному для каждого числа:

```coq
P 0 : Prop
P 1 : Prop
P 2 : Prop
```

Например, `P n` может означать «`n` является чётным». Применение `P n` только создаёт proposition — оно ещё не доказывает его.

Предикат от двух чисел:

```coq
R : nat -> nat -> Prop
```

принимает аргументы последовательно:

```coq
R x   : nat -> Prop
R x y : Prop
```

`R x y` может означать, например, «`x` меньше `y`».

## 7. `forall` также описывает функцию

```coq
forall n : nat, P n
```

означает, что для каждого `n` можно получить доказательство `P n`.

Если:

```coq
h : forall n : nat, P n
```

то `h` можно применить к конкретному числу:

```coq
h 3 : P 3
```

В записи:

```coq
forall n, P n -> Q n
```

тип `n` обычно выводится из `P n` и `Q n`. Полная форма:

```coq
forall n : nat, P n -> Q n
```

Разница между `->` и `forall`:

```coq
A -> B
```

результат `B` не зависит от имени принятого доказательства, а в:

```coq
forall n : nat, P n
```

тип результата `P n` зависит от переданного `n`.

## 8. Безымянная функция: `fun`

```coq
fun x => выражение
```

создаёт функцию без отдельного имени.

Например:

```coq
fun x : nat => x
```

имеет тип:

```coq
nat -> nat
```

Функция от двух последовательных аргументов:

```coq
fun x y => выражение
```

является сокращением для:

```coq
fun x => fun y => выражение
```

Применение функции вычисляется подстановкой:

```coq
(fun x : nat => x) 3
```

вычисляется в `3`.

## 9. Функции могут принимать другие функции

Тип:

```coq
nat -> (nat -> nat) -> nat
```

описывает функцию, которая принимает:

1. `n : nat`;
2. `f : nat -> nat`;
3. возвращает `nat`.

Примеры выражений этого типа:

```coq
fun n f => n
fun n f => f n
fun n f => f (f n)
```

Тип говорит, какие аргументы разрешены и каков тип результата, но не говорит, как именно аргументы используются.

## 10. Разбор определения `Leibniz`

Во втором файле есть:

```coq
Definition Leibniz (T : Type) (x : T) :=
  fun y => forall P : T -> Prop, P y -> P x.
```

По частям:

```coq
T : Type
```

`T` — некоторый тип, например `nat`.

```coq
x : T
```

`x` — значение этого типа.

```coq
fun y => ...
```

создаётся функция, принимающая ещё одно значение `y : T`.

```coq
forall P : T -> Prop, ...
```

доказательство должно работать для любого предиката `P` над значениями типа `T`.

```coq
P y -> P x
```

если предикат верен для `y`, он должен быть верен и для `x`.

Поэтому:

```coq
Leibniz T x     : T -> Prop
Leibniz T x y   : Prop
```

А доказательство:

```coq
h : Leibniz T x y
```

можно применять как функцию:

```coq
h P : P y -> P x
```

## 11. `exists` как объект с двумя частями

Чтобы доказать:

```coq
exists x : T, P x
```

нужно предоставить:

1. свидетель `x : T`;
2. доказательство `P x`.

Тактика:

```coq
exists value.
```

выбирает свидетель и оставляет цель, что он удовлетворяет предикату.

Если доказательство существования находится в контексте:

```coq
h : exists x, P x
```

то:

```coq
case: h => [x hx].
```

извлекает свидетель `x` и доказательство `hx : P x`.

## 12. Как читать сложный тип

Разбирай его в таком порядке:

1. Найди внешнюю, последнюю стрелку с учётом скобок.
2. Определи тип первого аргумента и тип оставшейся функции.
3. Для каждого `forall` выпиши имя и тип аргумента.
4. Для каждого применения через пробел вычисляй тип слева направо.

Пример:

```coq
forall x, P x -> exists y, Q y
```

читается так:

1. принять произвольный `x`;
2. принять доказательство `P x`;
3. вернуть свидетель `y` вместе с доказательством `Q y`.

## Короткая памятка

```coq
x : T                  (* x имеет тип T *)
f : A -> B             (* функция из A в B *)
f x                    (* применение функции *)
A -> B -> C            (* A -> (B -> C) *)
f x y                  (* (f x) y *)
P : nat -> Prop        (* предикат *)
P n : Prop             (* proposition *)
h : P n                (* доказательство proposition *)
forall x : T, P x      (* функция, дающая P x для каждого x *)
fun x => body          (* создание безымянной функции *)
exists x, P x          (* свидетель x и доказательство P x *)
```
